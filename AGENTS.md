# AGENTS.md

Instructions for coding agents working **on** this repository are in
[`CLAUDE.md`](CLAUDE.md): the build and test commands, the layering rules, and
what a change to a sampler has to record. They apply whichever assistant you
use. `CLAUDE.md` is only the file name Claude Code looks for.

If you are **using** BayesTS instead (writing a model file, running `bayests`,
reading the draws back), read [`agents/AGENTS.md`](agents/AGENTS.md).
